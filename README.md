# Task Manager

Простое desktop-приложение для управления задачами на Python + Tkinter.

## Установка
1. Установите Python 3.x
2. Склонируйте репозиторий

## Запуск
python gui.py

## Использование
1. Введите название, описание и срок (формат ГГГГ-ММ-ДД).
2. Нажмите «Добавить» — задача сохранится в tasks.json.
3. Выберите задачу в списке и нажмите «Удалить».

## Функциональность
- Добавление и удаление задач
- Автосохранение в JSON
- Загрузка задач при запуске

## Технологии
- Python 3.x
- Tkinter (GUI)
- JSON (хранение данных)
